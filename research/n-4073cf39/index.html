離宮・大邸宅の配置（復元検討メモ）

作成日: 2026-08-19 ／ 出典: 井内さん提供の「平安京の主な邸宅」地図（赤枠図）。個別の文献照合は未実施で、位置・占有町数は図からの読み取り。

反映した邸宅（IMPERIAL_ESTATE_DEFS・11邸）

  • 冷泉院・六條院（河原院）は天皇の離宮的な性格（広い庭池）。他は摂関家クラスの大邸宅
  • 冷泉院 / 高陽院 / 陽成院 / 町尻殿 / 堀河院 / 閑院 / 二条宮 / 東三条院 / 小二条院 / 山吹殿 / 六條院
  • 占有町数（choX×choZ）は図の面積から推定。矩形は町セルへスナップし間の小路を呑み込む
  • 建築は寝殿造variant1テンプレを敷地スケールで拡大（建物自体は等倍）。検査: residences=136・variantCounts[1]=18

町堂2（HALL_TEMPLE_DEFS）

  • 六角堂（頂法寺）=六角形の堂。研究メモ: 頂法寺.md
  • 因幡堂（平等寺）=方形の堂
  • 2026-08-19 v2: 町の予約をやめ「4分割の雑居町」へ（井内さん指示）。堂は1/4区画=六角堂は北東（図で右上）・因幡堂は南西（推定）。残り3/4は混在町のmixedPreset（官人宅・庶民長屋・従者長屋）＝いろんな階級と雑居
  • THREE直組みのhallsGroup（nobleLayer内）。混在町メカニズム（c.mixedEstate）で堂の2モジュール枠を空ける

神泉苑の乾臨閣（2026-08-19）

  • 出典: 井内さん提供の神泉苑復元図＋基礎調査（神泉苑.md）。「敷地の北部には乾臨閣を主殿とし、右閣、左閣、西釣台、東釣台、滝殿、後殿などを伴う宏壮な宮殿」の記述と整合

2026-08-19 v2: 中身の作り直し（井内さん指示）

  • 2町幅（冷泉院・高陽院・六條院）: 塀と大池は敷地全体で1つ（外周のみ）。中に寝殿造2棟を左右非対称に=西棟は一町邸を少し南寄り・東棟は半町邸（釣殿1つ）
  • 全離宮（1×2含む）の北帯に馬屋（細長い厩）1棟＋倉・使用人の家（2町幅は2列）＝計30棟（馬屋5・倉17・雑舎8）
  • 寝殿造の全敷地（京内の邸含む）へ植栽: 池の周囲の環＋建物の北側、3種（広葉・松・低木）×大小、計約1500本
  • 神泉苑: 池畔の環＋外周＋中島に混植（種類・大小のばらつき）、苑池に楽舟（屋形・貴人2・従者1・船頭1）、群衆は池でなく乾臨閣前庭へ

2026-08-19 v3: 900年時点の主の比定と個別化・朱雀院追加

  • 900年頃の主: 六條院=源融旧邸（895没）・陽成院=陽成上皇の御所・冷泉院=天皇家の後院・堀河院/閑院=藤原氏（基経ゆかり）
  • 朱雀院を追加: 宇多上皇の後院。右京四条一坊の8町（朱雀西・三条南〜四条北・東西2町×南北4町・大内裏に次ぐ規模）。出典=Wikipedia「朱雀院」（2026-08-19確認）。北に正殿・中段東に対の殿・南半分は大池の苑
  • 棟構成の個別化（「冷泉院と斜め隣が同じ形」解消）: layout/vをIMPERIAL_ESTATE_DEFSに持たせてdata-driven化。冷泉院=v1南寄り＋v2／高陽院=左右鏡像構成／六條院=庭園邸（v1北西＋v3の亭）／1町邸は陽成院v2・町尻殿v3・閑院v2・東三条院v2・小二条院v3など市松で同型隣接を回避

2026-08-19 v4: 高陽院の年代検証（井内さんの「入れちゃったな」への回答）

  • 撤去不要。有名な高陽院（頼通の4町豪邸・里内裏）は1021年以降で範囲外だが、前身の賀陽親王邸は9世紀から実在する。名前も親王由来（「賀陽院」とも）
  • 出典: 高陽院 (邸宅)（Wikipedia）＝当初は桓武第七皇子・賀陽親王邸、中御門南・堀川東、後に所有者転々。高陽院跡（コトバンク）＝『拾芥抄』「中御門南堀川東、南北二町」
  • 規模2町は実装と一致。位置も中御門南・堀川東で現配置の根拠になる
  • 901年時点の設定: 賀陽親王（794-871）没後30年の旧邸。皇子の家として格は高いが主は代替わりしており、頼通期の華やかさはない
  • 直すなら呼称のみ: ゲーム内ラベルを「賀陽院（賀陽親王旧邸）」にすると年代的に最も正確。「高陽院」表記のままでも同一邸の別表記なので誤りではない

2026-08-19 v5: 朱雀院の殿舎と使われ方（井内さんの質問「どんな建物があったのか」）

殿舎（文献で分かる範囲）

  • 寝殿造で、内裏に準じた殿舎を持っていた。名前が伝わるのは仁寿殿・宜陽殿など（Wikipedia「朱雀院」2026-08-19確認）。内裏の殿舎名をそのまま使っている＝「もうひとつの内裏」として作られた後院
  • 成立は嵯峨朝（承和年間頃）。宇多上皇が整備して譲位後の御所にした。のち朱雀天皇も修理して住む。950年焼亡→村上天皇再興→円融以降荒廃
  • 個々の殿舎の配置図は伝わっていない（発掘でも殿舎配置は未確定）。現実装の「北に正殿・対の殿・南半分は大池の苑」のうち大池は他の後院（冷泉院・神泉苑）からの類推＝推定と明記しておく

ゲームへの反映（実装は今はしない）

  • 馬場は確実にあった（競馬・駒牽の2記録）。8町の敷地の南寄りか東寄りに馬場の帯を置くと考証が立つ。将来の改修候補
  • 朱雀院は「隠居所」ではなく上皇の宮廷。年始の朝覲行幸は都の年中行事で、行列が朱雀大路→三条を渡る＝群衆イベントにできる
  • 911年の亭子院酒合戦（紀長谷雄「亭子院賜飲記」）は朱雀院でなく亭子院（七条）の水閣。混同しない
  • 源氏物語の「朱雀院行幸」（紅葉賀）はこの実態の文学的反映。試楽を内裏でやってから行幸する構造も朝覲行幸の型どおり
