前提：京内に自然の川がない

「平安京」 の記述が出発点になる。長岡京の洪水を避けて、平安京は自然河川を京域内に入れない設計になっている。その代わりに東西へ「堀川」「西堀川」を掘り、水運と生活廃水路を兼ねさせた。鴨川・桂川は京域の外を流れ、京内には入らない。

つまり荷の流れは3段階になる。外港（淀川水系）→ 小舟へ積み替え → 堀川・西堀川で京内へ。 陸送（鳥羽作道→羅城門）はこれと並行する別経路で、船に載せられないものと運脚の背負い荷がそちら。

⚠️ 2026-09-04 訂正: 「陸送で京内へ」と書いたのは誤り

初版はこの節を「外港 → 京近郊の津 → 陸送で京内へ → 京内は運河」と書き、 「船が羅城門をくぐって都に入るわけではない」と付けていた。井内さんの指摘（「小舟に載せ替えて運ぶための堀川なのでは」）で見直したところ、陸送を主経路として書いたのが誤りだった。

  • 堀川は物資の運搬用に掘られた運河で、「運河としての用途は、上流下流からの木材の運搬」とされる

（第58回 親水公園になった平安京造営時の運河を散策する）。 下流から運ぶ＝南の鴨川・桂川の側から遡って入ってくる。

  • 「平安京には、物資の運搬用として左京と右京にそれぞれ運河が掘られ」（平安京での南北の運河「西堀川」の遺構を見た）
  • 羅城門は朱雀大路（x=0）の門で、堀川は x=±8605.2。軸が違う。

だから「船が羅城門をくぐらない」は正しいが無意味な指摘だった。運河には独自の南の入口がある。

  • 実装は九条で切らず、堀川を現況堀川（OSM）経由で鴨川へ、西堀川を真南で桂川へ繋いでいる＝両端が外の川に通じている。
  • 西堀川小路の発掘で荷車の轍が出ているので、運河の脇を荷車も通った。水と陸の併用が正確なところ。
  • 実装側は既に正しかった（addHeianCanalBoats()で東市の横に俵積みの舟3艘＝都の中まで舟が来ている）。

記録の文章だけが陸送に寄っていた。

第1段 外港

津位置性格
山崎津桂川・宇治川・木津川の合流点付近文献に「平安京の外港」として見える。淀川水運と陸路の中継点
淀津桂川右岸の大下津・水垂を中心に、一部対岸の納所を含む水陸の結節点。平安末〜鎌倉には「魚市」として知られる
草津湊中島・下鳥羽・横大路の辺りとされるが特定できない平安時代から都へ物資を運ぶ湊
大井津桂川上流側（嵐山方面）「平安京」 が淀津と並べて挙げる港

瀬戸内・西国・南海の荷は淀川をさかのぼり、東国・北陸の荷は琵琶湖から宇治川を下って、この帯に集まる。巨椋池は「古代・中世を通じて水上交通の中継地」（「巨椋池」）で、この一帯そのものが港域だった。

第2段 陸送

  • 鳥羽作道は「平安京建設時に淀川から物資を運搬するために作られた道」と考えられている（「鳥羽作道」）。淀・鳥羽の津から羅城門まで真北に伸びる、荷専用の幹線と見ていい。
  • 陸上交通は巨椋池を避けて盆地の外縁を通った（「巨椋池」）。つまり池は船で越え、陸路は迂回する。
  • 丹波の材木は桂川を筏で下し、嵐山で京都盆地に入る。桂川は上流の杉材を都の造営へ運ぶ主要ルートだった。

第3段 京内の運河

ここが今回の本題。堀川は1本ではなく、左京と右京に1本ずつある。

運河沿う小路現在地状態
堀川東堀川小路（左京）現在の堀川通現存。造営時に元からあった川を開削した運河で、明治期まで木材運搬に使われた
西堀川西堀川小路（右京）現在の西大路通の東隣痕跡は地上に残っていない。発掘で検出される
  • 「平安京」 は「堀川小路と西堀川小路では中央に川（堀川、西堀川）が流れていた」とする。小路の中央を水が流れ、その両側が路面という断面になる。現在の堀川通に東堀川通・西堀川通の2本があるのは、この構造がそのまま残ったもの。
  • 小路の幅は4丈（約12メートル）。その中央を占める水路なので、川幅は数メートル規模と考えるのが妥当（数値は史料未確認）。
  • 用途は2つ。水運（とくに材木・薪炭）と、生活廃水の排出。
  • 2025年8月の発掘では西堀川小路の路面がそのまま出土し、荷車の轍跡が確認された。運河と並んで陸の荷車も通っていたことになる。
  • 京都市埋蔵文化財研究所の報告名は「平安京右京四条二坊十一町・西堀川小路跡」。右京四条二坊が調査地。

実測から決めた手順

現況の堀川は水系データ heian-water-data.js の current.rivers に名称付きで入っている（OSM由来・widthM 14・16点）。京内区間は暗渠でOSMに無いが、八条以南の残存区間が拾えていて、その北端から約500mは経度がほぼ一定に走る。

  • 現況堀川の経度 = 135.75204（x換算で 8788）
  • アンカーは lat 35.0199 / lon 135.7424、1単位=0.1m。経度1度=91,165m、緯度1度=111,319m

3Dの主要地点を逆変換すると、この座標系が現地と正しく合っていることが確認できる。

地点3D座標逆変換した緯度経度現地
東寺4624, 4253734.98169, 135.74747一致
大将軍堂-8450, -674035.02595, 135.73313現・大将軍八神社と一致
五條天神13080, 2309134.99916, 135.75675現・五條天神宮と一致

そのうえで現地の3本の東西位置を3D座標へ置き換える。

  • 大宮通 ≒ x 5899（東寺の東縁。「東寺西寺_発掘リーフレット071」 の実装値）
  • 堀川 ≒ x 8788（上記の実測）
  • 西洞院大路 = x 13530（グリッド軸。現・西洞院通と一致）

真因は座標のずれではなく、軸の名前が1本ずれていること

現況堀川の x=8788 は、既存の大路軸「東大宮大路」（9020）とわずか232（23m）しか離れていない。検証できる5点を並べると、3Dの軸は現代の街路にきちんと乗っていて、狂っているのは軸に付けた名前だけだとわかる。

つまり大宮大路は「大内裏東側路」という名前で正しい位置に入っており、本来の堀川小路の線が「東大宮大路」と呼ばれている。堀川は既存の ±9020 軸の中央に流せばよい。

撤回した誤り（同じ間違いを繰り返さないため）

  • 「外側 ±11996.7＝西大路通の東隣と合う」→ 誤り。現代の street 名から距離を当てる推定を、照合可能な実測点を持たずに行った。
  • 「大路の間隔は4510で一様」→ 誤り。実際は朱雀大路から 3199・2861・2960・4510・4510・4510 で、中央部は密。外側の3つだけを見て一様と決めつけた。
  • 「現地の千本通は皇嘉門大路（-3226）付近」→ 根拠なし。千本通を照合できる実測点を持っていない。
  • 「比率で写して内側 ±10553.3」→ 誤り。前提の一様間隔が誤りだったので比率写しそのものが不要だった。

🚫 教訓：位置を決めるときは、現代の街路名からの距離感で当てず、heian-water-data.js のOSM実測か、既に現地一致を確認済みの地点（東寺・大将軍八神社・五條天神）から逆算する。

独立した裏付け：東西市との位置関係（2026-08-18）

井内さんが提示した街路名入りの条坊図から「西市の西、東市の東を川が通る」という読みが出た。実測で決めた ±9020 と一致する。

市の範囲運河の水面隙間
東市x 6310..87108996..9044東縁から 28.6m
西市x -8710..-6310-9044..-8996西縁から 28.6m

運河は市のすぐ外側を、接触せずに通る。もし外側の小路（±11996.7）に置いていたら市から約330m離れてしまい、この読みに合わない。位置決めの根拠が、現況堀川のOSM実測と条坊図の2つで独立に一致した。

  • 塩小路（mutsunohana.net）は、東市が猪隈小路との交差点の北側、西市が西靫負小路との交差点の北側に接していたとする。市の東西の縁に別の小路があり、その外側に堀川・西堀川が来る構図で、上の28.6mという隙間はおおむねその小路1本ぶんに相当する。
  • この関係は canalMarketGap として検査に固定した（市に接せず0〜60m以内を通ること）。
  • 描き方は既存の水系レイヤーへ寄せる。HEIAN_WATER.historical.rivers は現在空配列で、certainty が「復元」で始まるものを「復元河川」、それ以外を「推定河川中心」として描き分ける経路がすでに動いている（makeWaterRibbons）。堀川・西堀川はここへ certainty:'推定' で入れるのが最も安い。色は HEIAN_WATER_COLOR で神泉苑・巨椋池と共通になる。
  • 流す線は既存の大路軸 x=±9020。実測（±8788）との差23mは、条坊グリッド全体の丸めの範囲内なので軸に乗せる。
  • 小路の中央を流れるので、幅は小路幅120（＝12m）より細くする。路面が両側に残る見え方が要件なので、水面幅は40〜50（4〜5m）程度から始めて目視で決める。
  • ⚠️ ±9020 の軸は道路幅300（30m）で引かれているが、堀川小路は小路なので本来120（12m）。ここを直すと町割りが動くので今回は触らない。幅40〜50の水面なら30m幅の路面の中に収まり、見た目の破綻はない。
  • 南北の範囲は京域内に限る。北端・南端の接続が未確認（前節）なので、一条大路から九条大路までを描いて京外へは出さない。ただし左京側は、九条以南に現況堀川の実測区間（x 8838→5225 で南西へ振れる）が既に current.rivers にあるので、京内区間の南端がそこへ向く向きになっているかは目視で確かめる。
  • 荷車の轍が出ていることから、運河沿いは陸送とセットで使われた。将来ゲーム側で「材木を運ぶ」動線を作るなら、この小路が候補になる。

今後の調査課題

  • 川幅・深さの発掘数値。2026-08-18に検索したが見つからなかった。 京都市埋蔵文化財研究所の西堀川小路跡（2015年報告）の本文にあたる必要がある。現状の3Dの水面幅48（4.8m）は小路幅12mに収まる値として置いた推定値。
  • 船岡山東麓から堀川小路の線までの源流部の経路。京外なので3Dには不要だが、給水の理解には要る。
  • 京内の他の水路。「平安京」 は堀川・西堀川を「始めとする河川をいくつも整備し」と書いており、他にもあったことになる。
  • 神泉苑への給水経路（鳥羽から引いたとする説の確認）。

外部ページの内容は原文を転載せず、位置関係と事実だけを要約した。

追記: 堀川と西堀川は証拠が非対称（2026-09-04）

井内さんの質問「西堀川も上流から木材を運んでたの？」への調べ。言えない。 木材運搬の記録は堀川（東）だけ。

堀川（東堀川小路）西堀川（西堀川小路）
現状現存。今の堀川通地上に痕跡なし。発掘でのみ検出
