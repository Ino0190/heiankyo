# 平安京 3D散策

平安京（794年頃）を国土地理院DEMとOpenStreetMap河川データの上に推定復元し、ブラウザだけで空から巡り、地上を歩けるコンテンツ。

- 入口: `index.html`（`heiankyo/index.html` へリダイレクト）
- 3Dエンジン: `CadKit/index.html`（three.js / manifold-3d / opencascade.js はCDNから取得）
- `heiankyo/terrain/heian-baked-assets*.js` は生成済み建築の焼き込み（自動生成物・手で編集しない）

地形: 国土地理院DEM ／ 河川: © OpenStreetMap contributors ／ 建築・区画: 史料に基づく推定
